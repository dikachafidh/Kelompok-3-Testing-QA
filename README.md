## Isi repositori
- `laporan/` : laporan pengujian (Test Plan, Test Case, Test Report)
- `izin/` : bukti izin pemilik website
- `evidence/` : screenshot hasil pengujian per test case
- `lighthouse/` : hasil pengukuran performa (Lighthouse)
- `interview/` : catatan wawancara dan validasi QA profesional

## Acuan
- Modul Testing dan QA Perangkat Lunak (Pertemuan 2 dan 16)
- ISO/IEC/IEEE 29119-5:2024 (pendekatan keyword-driven)
- ISO/IEC 25002:2024 (kerangka mutu)
